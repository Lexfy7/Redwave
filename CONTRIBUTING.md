# Contributing to Redwave

1. Open an issue describing the bug or proposed feature.
2. Fork the repository and create a focused branch.
3. Run `npm install` and `npm run build`.
4. Include screenshots for UI changes and tests for logic changes.
5. Submit a pull request with a concise description.

Do not commit credentials, access tokens, private user data, or generated build output. Keep Spotify API usage within the current developer terms.
